Progression

1 Terminal d'Accès

Pour entrer dans le cockpit, vous avez besoin d'une clé d'accès. La clé par défaut est admin:studies:secret. Elle agit comme une empreinte digitale sécurisée.

Astuce: En production, chaque administrateur doit générer sa propre clé via le script CLI.

2 Analytics Intelligence

Regardez les KPIs en haut du Dashboard. Le "Success Rate" est votre pouls. S'il descend en dessous de 80%, c'est qu'un processeur rencontre des difficultés.

Operational: 80-100%
Critical: < 50%

3 Gestion des Agrégateurs

Un processeur (PSP) est en maintenance ? Ne paniquez pas. Sur la page "Providers", vous pouvez "éteindre" un prestataire d'un simple clic. Le trafic sera redirigé automatiquement.

Commutation sans interruption de service (Zero-downtime)

4 Audit & Webhooks

Chaque clic utilisateur génère un "Webhook". C'est un message que le PSP envoie à votre système. Si une transaction semble bloquée, vérifiez les Webhooks pour voir si le PSP a bien confirmé le paiement.

Event: payment_intent.succeeded
