# Fix Remaining Payment System Issues

## Problem Analysis
Two critical issues remain after the initial fixes:

1. **WebhookEvent Database Error**: "Field 'createdAt' doesn't have a default value" - The `aggp_webhook_events` table has camelCase column names (`createdAt`) but Sequelize expects snake_case due to global config

2. **CinetPay transaction_id Error**: Despite model fixes, `transaction_id` is still missing from CinetPay payload, indicating `attempt.transactionNumber` is undefined

## Root Cause Analysis

### WebhookEvent Issue
- Database table `aggp_webhook_events` has `createdAt` column (camelCase)
- Global Sequelize config has `underscored: true` expecting `created_at`
- WebhookEvent model has `timestamps: true` but column naming mismatch causes insert failure

### CinetPay transaction_id Issue
- PaymentAttempt creation appears successful (no database errors)
- But `attempt.transactionNumber` property is undefined when accessed
- Likely issue with Sequelize field mapping or model configuration

## Database Table and SQL Fix

**Table Name:** `aggp_webhook_events`

**Issue:** Column `createdAt` exists but has no default value, causing insert failures.

**SQL Fix Options:**

```sql
-- Option 1: Add default value to existing camelCase column
ALTER TABLE aggp_webhook_events
MODIFY COLUMN createdAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP;

-- Option 2: Rename column to snake_case (if preferred)
ALTER TABLE aggp_webhook_events
CHANGE COLUMN createdAt created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP;
```
